# trufo_generator_product (Data Source)

Looks up a Trufo **generator product** (`POST /gproduct/list` / `/gproduct/info`). Products are created in the Trufo dashboard (as part of a Product Validation application), so this is read-only. Look up by `gp_id`, or by `name` (then `oid` is passed to the list call, which the server scopes to your credential's organization).

-> **Note** Generator products are created in the Trufo dashboard (as part of a Product Validation
application), so this data source is read-only. Look up by `gp_id` or by `name`. Requires a Bearer
access token (`access_token`/`refresh_token`).

## Example Usage

```terraform
data "trufo_generator_product" "by_id" {
  gp_id = "gp_..."
}

data "trufo_generator_product" "by_name" {
  name = "my-generator-product"
  oid  = "org_..." # required by /gproduct/list; the server scopes to your credential's org
}

output "pv_active" {
  value = data.trufo_generator_product.by_id.pv_active
}
```

## Schema

### Optional

- `gp_id` (String) Generator product ID (`gp_…`) to look up directly. Exactly one of `gp_id` / `name` must be set.
- `name` (String) Product name to match when listing. Exactly one of `gp_id` / `name` must be set.
- `oid` (String) Organization ID passed to `/gproduct/list` (required by its request schema; the server uses your credential's organization). When looking up by `gp_id` and `oid` is unset, the ID is resolved from `/gproduct/info`.

- `created_at` (String)
- `created_by` (String)
- `id` (String) Generator product ID (`gp_…`).
- `implementation` (String)
- `pv_active` (Boolean) Whether the Product Validation is approved and unexpired — required before instances can be created.
- `pv_status` (String) Product Validation status.
- `validated_expires_at` (String)
