# trufo_instance_credential (Resource)

A Trufo **instance credential** — a public key enrolled for an instance (`POST /gproduct/instance/credential/register`). The matching private key signs the client assertion that requests CSR JWTs for certificate enrollment; the private key never leaves your systems. An instance may hold at most **two active credentials**: register the replacement, cut over, then revoke the old one. Deleting this resource revokes the credential (permanent). Auth: an MFA-verified access token (`access_token`/`refresh_token`). On the test host, a `gproduct-admin` scoped API key is also accepted (verified against test.api.trufo.ai; the scope is not listed in the trufo-py docs).

~> **Warning** Deleting this resource **revokes** the credential on the server. Revocation is permanent.

-> **Note** An instance may hold at most **two active credentials** — that cap is what makes key
rotation possible: register the replacement, cut over your signer, then remove the old resource.
See the [key rotation guide](../guides/key-rotation.md).

-> **Note** Only the **public** key is enrolled here (`public_key_pem`). The private key never enters
Terraform state; it stays on your signing systems and signs the CSR-JWT client assertion used for
certificate enrollment (`POST /ra/c2pa/csr-jwt`).

## Example Usage

```terraform
resource "trufo_instance" "signing_service" {
  gp_id = "gp_..."
  name  = "signing-service-eu-1"
}

# Enroll a public key on the instance. The private key stays on your side and
# signs the client assertion used for certificate enrollment. An instance
# holds at most two active credentials — rotate by adding the replacement
# first, then removing the old one (delete = revoke).
resource "trufo_instance_credential" "primary" {
  gpi_id         = trufo_instance.signing_service.id
  public_key_pem = file("instance-public-key.pem")
  key_algorithm  = "ES256" # EC P-256; EdDSA (Ed25519) also accepted
  label          = "primary-2026"
}
```

## Schema

### Required

- `gpi_id` (String) Instance ID (`gpi_…`) to enroll the key on. Changing this forces recreation.
- `key_algorithm` (String) JWA algorithm matching the key: `ES256` (EC P-256) or `EdDSA` (Ed25519). Changing this forces recreation.
- `public_key_pem` (String) PEM-encoded public key. Changing this forces recreation (a new registration).

### Optional

- `label` (String) Human-readable label for the credential.

### Read-Only

- `created_at` (String) Registration timestamp (RFC 3339).
- `id` (String) Credential ID (`gpic_…`).
- `revoked` (Boolean) Whether the credential has been revoked.
- `revoked_at` (String) Revocation timestamp (RFC 3339), if revoked.

## Import

This resource can be imported using `{gpi_id}/{gpic_id}`, e.g.

```shell
# Import a credential as "{gpi_id}/{gpic_id}"
terraform import trufo_instance_credential.primary gpi_01a1c4b6-0000-0000-0000-000000000000/gpic_01a1c4b6-1111-1111-1111-111111111111
```
