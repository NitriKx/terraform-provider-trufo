# trufo_instance (Resource)

A Trufo generator product **instance** — one signing identity within a generator product (`POST /gproduct/instance/*`). Instances hold their own credentials and are issued their own certificates. Requires an active Product Validation on the product. Auth: an MFA-verified access token (`access_token`/`refresh_token`). On the test host, a `gproduct-admin` scoped API key is also accepted (verified against test.api.trufo.ai; the scope is not listed in the trufo-py docs).

-> **Note** An instance is one signing identity within a generator product: it holds its own
credentials and is issued its own certificates. Creating an instance requires the product to have an
active Product Validation (`pv_active` on the `trufo_generator_product` data source).

## Example Usage

```terraform
data "trufo_generator_product" "by_name" {
  name = "my-generator-product"
}

resource "trufo_instance" "signing_service" {
  gp_id = data.trufo_generator_product.by_name.id
  name  = "signing-service-eu-1"
}
```
